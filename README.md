# Wayfare

Study the Word. Enjoy the Journey.

Christian youth card game. Version 1 is an offline-first Expo app that ships as a PWA.

## Scripts

```bash
npm install
npm run start
npm run typecheck
npm run lint
npm run test
npm run build:web
```

Open the web build with `npx serve dist`. Full architecture and deploy notes are added as the build stages land. See `docs/DECISIONS.md`.
