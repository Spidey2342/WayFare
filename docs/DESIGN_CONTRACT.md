# Debate V2 design contract (from `reference/debate designs/`)

Source frames are read-only PNGs under `reference/debate designs/` (see `docs/QUESTIONS.md` for path note).

## Group: Topic and sides

- **DEBATE MODE**
- **CATEGORY: FAITH & TECH** (dynamic category from topic)
- Topic example: *Is social media doing more harm than good for youth ministries?*
- *Be sharp, be kind. The best arguments are built on grace and logic.*
- **USE THIS TOPIC** / **SHUFFLE TOPIC**
- **LEADER IS CHOOSING A TOPIC...**
- **CHOOSE SIDES** / **CHOOSE YOUR SIDE**
- **AGREE** / **DISAGREE**
- **THE JUDGE**
- Waiting for at least 1 player on each side
- **START DEBATE**
- **WAITING FOR LEADER TO START**

## Group: Progress and verdict

- Elapsed chip (example **12:40**)
- **CURRENT TOPIC**
- **READY FOR VERDICT**
- Soft timer: **3 MIN**, **5 MIN**, **10 MIN**, **No limit**
- Nudge: **Time's up. Keep going or wrap up?**
- **FINAL JUDGMENT**
- **Who made the stronger case?**
- **AGREE** / **DISAGREE** / **= IT'S A DRAW**
- **SELECT MVP (OPTIONAL)**
- **ANNOUNCE WINNER**
- **DEBATE CONCLUDED**
- **The leader is deciding...**
- *Great arguments everyone! Let's see who took the crown this round.*
- **JUDGE** + name
