# Wayfare Learn content (pack 1)

| File         | What it holds                                                                                       |
| ------------ | --------------------------------------------------------------------------------------------------- |
| books.json   | All 66 books: testament, group, chapter count, one-line summary                                     |
| quiz.json    | 60 multiple-choice questions in 6 categories (10 each) with explanations and references             |
| lessons.json | 4 study paths x 3 lessons = 12 lessons, matched to the Identity, Courage, Serving and Journey decks |

Scripture text is KJV (public domain). Lesson summaries are written in original wording.
Verify every verse and fact against your own Bible before launch.
Put files in `src/data/learn/` and the schema in `src/features/learn/learn.schema.ts`.
